# Kịch bản video demo automation — cần sinh viên tự quay

Thời lượng mục tiêu: 6–8 phút. Link sau khi quay: **`<UNLISTED_YOUTUBE_AUTOMATION_DEMO_LINK_REQUIRED>`**.

1. Mở terminal, chạy `whoami` và `hostname` để chứng minh tác giả.
2. Giới thiệu ba feature FR-06, FR-09, FR-17 và 36 test case trong `test-cases/`.
3. Mở một JSON trong `test-data/` và spec tương ứng để giải thích data-driven testing.
4. Chạy `npm run list`, chỉ ra 108 test execution trên ba browser.
5. Chạy `npm run run:matrix`; giải thích exit code 1 là do lỗi SUT thật, runner vẫn chạy đủ chín cell.
6. Mở report HTML của một feature trên Chromium, Firefox và WebKit; chỉ ra `Run by: 23127065` và ISO timestamp.
7. Trình bày một lỗi đã sửa trong automation: locator label không accessible hoặc race condition của Coupon Admin.
8. Mở screenshot lỗi percentage coupon và GitHub issue #27.
9. Kết thúc bằng kết quả 54 pass, 54 fail, 9 bug và lệnh audit trả `errors: []`.
